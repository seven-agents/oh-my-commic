## TODO（按优先级）

### P0 — 尽快（工程质量/稳定性最先咬人的）
- [ ] **加 CI**（GitHub Actions）：`go test -race ./...` + `go vet` + `cd web && npm run build`，PR 必过。当前全靠手动，回归风险高。
- [ ] **扫掉其余"双提交"隐患**：`CreateBookModal`(建书)、`AssetEditor`(存资产) 等仍是 `setState` 异步守卫，同章节那个 bug 一样会建重复数据 → 统一改 `useRef` 同步守卫（可抽 `useSubmitOnce` hook）。
- [ ] **更新 `docs/frontend-api.md`**：storyboard-chat 现在只出 content、新增 `POST /api/panels/{id}/process`、Panel 加 `content`、Chapter 加 `conversation/panelCount` —— 文档已与代码不符。
- [ ] **保护线上配额**：部署实例是**公网 + 开放注册**，任何人可注册烧掉付费 API 额度 → 加注册口令/白名单，或不用时 `docker compose down`。
- [ ] **轮换已暴露的 key**（DashScope + 火山 Ark，对话/`.env` 里都出现过）→ 改后更新服务器 `.env` 重启。
- [ ] **AI 错误分类友好提示**：区分"配额用完/限流/超时"与通用 502，前端给可读提示（现在全是"AI 服务暂时不可用"）。

### P1 — 应做（功能完整性 + 健壮性）
- [ ] **分镜可"加"角色**：现在只能删 chip，补一个"添加出场角色"选择器（从书里角色选）→ 修正索引。
- [ ] **导出成品书**：整本/单章导出为图片或 PDF（"完成"的自然出口，DEMO 里列为 Could）。
- [ ] **孤儿图片清理**：删书/删章时清 `data/{bookId}/` 下的图片（现在只删 DB 记录，文件残留）；或加定期清理。
- [ ] **封面章删除处理**：删封面章时清 `book.cover_url`；阅读器"只有封面"时也能展示封面页。
- [ ] **AI 调用重试/退避**：对瞬时上游错误(5xx/超时)做有限重试；render/process/comicify 超时参数化。
- [ ] **上限治理**：session 加 TTL、conversation 存储/回传做长度上限（现在都无界增长）。
- [ ] **概述补生成**：给"概述功能前"建的老章节一个"生成概述"入口/批量回填。

### P2 — 可选 / 中长期
- [ ] **异步出图 + 进度**：render 改为提交任务→轮询/WebSocket，不再长同步占连接，刷新可恢复、体验更好、规模化必需。
- [ ] **出图并发限流**：当前"全部生成"无上限并发，加个并发池(如 3)防上游限流/内存峰值。
- [ ] **分享/点赞（公开广场）**：`is_public` 落地，书架加公开浏览 + 点赞。
- [ ] **可观测性**：结构化日志 + 基本指标 + 错误上报；`/api/health` 之外加就绪探针。
- [ ] **部署强化**：Docker secrets 替代 env_file；域名 + Nginx + HTTPS；SQLite 卷定时备份。
- [ ] **清理累计 Minor**：`t.Setenv`、sentinel error、`sanitizePanel` 去重、迁移改 pragma 判重、书架/资产分页等（散落在各 review 记录）。
- [ ] **前端测试**：给关键流程(登录、建书、两段式分镜、出图门控)加 Vitest/Playwright，补上最大的质量缺口。
