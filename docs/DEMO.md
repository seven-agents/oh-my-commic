# oh-my-commic · 3 分钟演示脚本

面向面试的现场走位。目标：用 3 分钟讲清三个亮点——
**① 多用户隔离 · ② AI 索引角色/场景 · ③ 参考图锁一致性 + 逐格生图**。

## 0. 开场准备（演示前，不计时）

- 已构建前端并启动单服务：
  ```bash
  cd web && npm install && npm run build && cd ..
  go run ./cmd/server            # 打开 http://localhost:8080
  ```
- `.env` 里已填好两个 Key：`DASHSCOPE_API_KEY`（千问·对话）+ `ARK_API_KEY`（火山方舟·出图）。
- 建议：提前准备好 1 张角色图（比如一只小狐狸）+ 1 张场景图（森林），演示上传时直接选。
- 一句话总纲：**「用户建一本书，创建自己的角色和场景，一句话 + 和 AI 聊分镜，逐格生图，拼成一本吉卜力风的漫画书。」**

---

## 1. 多用户隔离（约 30s）

**操作**
1. 打开 http://localhost:8080 → 注册用户 A（昵称 `小明` / 任意密码）。
2. 进入书架（空态：`还没有漫画书哦`）。右上角头像菜单 → **退出**。
3. 再注册用户 B（昵称 `小红`）。书架同样是空的。

**话术亮点**
- 「每个用户登录后只能看到自己的书、角色、章节——**隔离是在后端强制的**：所有受保护路由都走 `RequireUser` 中间件，Repository 层每条查询都带 `user_id` 过滤，不是靠前端藏。」
- 「Cookie 会话 + SQLite 存储，注册即隔离，跨用户互相看不到。」

> 讲完切回 **用户 A**（重新登录 `小明`）继续下面的主线。

---

## 2. 建书 + 建资产（约 45s）

**操作**
1. 用户 A 书架 → **创作新书**，书名《小狐狸的森林冒险》→ 进入 Book 工作台。
2. 资产区新增 **1 个角色**：`小狐狸` → 上传角色图 + 填人设（活泼、橙色皮毛）。
3. 新增 **1 个场景**：`森林清晨` → 上传场景图 + 填描述。

**话术亮点（第 3 个亮点的前半：参考图）**
- 「一本书是一个『宇宙』：角色和场景挂在 Book 上，**跨章节复用**。」
- 「这里上传的图不是装饰——它是**参考图**。生图时会带着它，锁住同一角色在不同分镜里的形象一致性，这是漫画最难的地方。」

---

## 3. 建章节 + 讲故事对话（约 40s）

**操作**
1. Book 工作台 → 新建 **章节**：`第一章 · 迷路的小狐狸` → 进入 Chapter 编辑器（核心页）。
2. 左侧对话框输入一段故事介绍，例如：
   > 「小狐狸清晨在森林里醒来，发现自己迷路了，它一边害怕一边鼓起勇气找回家的路。」
3. 和 AI 来回聊一两轮，让它把这段话**聊成一组分镜脚本**。

**话术亮点**
- 「这是对话式分镜：用户给一句话，AI 帮忙拆成一格一格的镜头脚本，人可以继续追问、调整。」

---

## 4. 生成分镜 → AI 索引出场角色/场景（约 30s）

**操作**
1. 点击 **生成分镜**，得到 pic1、pic2、pic3… 一组分镜。
2. 逐格指给面试官看：**每一格都自动标注了『出场角色 / 使用场景』**。

**话术亮点（第 2 个亮点，重点讲）**
- 「注意这里——**AI 读故事，自动决定每个分镜里出场哪些角色、用哪个场景**，从这本书已有的资产里『索引』出来，不需要人一格一格手动挂。」
- 「所以生图时就知道该带哪张参考图，把亮点 ② 和亮点 ③ 串起来了。」

---

## 5. 逐格生图（吉卜力风）→ 拼成书（约 40s）

**操作**
1. 对某一格点 **生图**：AI 带着该格索引到的角色/场景参考图，生成一张**吉卜力 / 宫崎骏风格**的画面。
2. 再生 1～2 格，指出**同一只小狐狸形象保持一致**。
3. 点 **拼版 / 拼成书**，把生成的分镜拼成漫画页。

**话术亮点（第 3 个亮点的后半：一致性 + 逐格生图）**
- 「逐格生成，每张都把参考图喂给生图模型（火山方舟 Seedream `doubao-seedream-4-0-250828`，最多 10 张参考图），**同一角色跨格一致**，风格默认吉卜力。」
- 「生成的图片落地到本地存储，通过 `/media/*` 提供——和 API 同一个服务、同一个端口。」

---

## 6. 阅读成品（约 15s）

**操作**
1. 进入 **漫画阅读** 页，翻页看拼好的成品书。

**收尾话术**
- 「一句话回顾：**多用户隔离的账号体系 + 一本书一个宇宙的资产模型 + AI 自动索引出场角色 + 参考图锁一致性的逐格生图**——从建书到阅读，完整闭环。」

---

## ⏱️ 时间预算

| 步骤 | 时长 | 对应亮点 |
|---|---|---|
| 1 多用户隔离 | ~30s | ① 隔离 |
| 2 建书 + 资产 | ~45s | ③ 参考图（前半） |
| 3 章节 + 对话 | ~40s | 对话式分镜 |
| 4 生成分镜 | ~30s | ② AI 索引 |
| 5 逐格生图 + 拼版 | ~40s | ③ 一致性 + 逐格 |
| 6 阅读 | ~15s | 收尾闭环 |
| **合计** | **~3 分钟** | |

## 兜底话术（网络/生图卡住时）

- 生图依赖外部火山方舟（Ark Seedream），若现场网络慢：先展示**已生成的分镜**和**索引结果**，说明「生图是逐格的，慢在模型侧，架构上分镜脚本和索引已经完成」。
- 后端可 API-only 运行；若前端未构建，`go run ./cmd/server` 仍提供全部 `/api/*`，可用 `curl localhost:8080/api/health` 证明服务在线。
